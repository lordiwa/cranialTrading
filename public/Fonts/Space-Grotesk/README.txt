Space Grotesk Variable Font
============================

This download contains Space Grotesk as a variable font (latin subset).

Space Grotesk is a variable font with this axis:
  wght (300-700)

This means the weights used by Cranial Trading (500, 600, 700) are all
contained in a single file:
  SpaceGrotesk-Variable.woff2

Source: Google Fonts (https://fonts.google.com/specimen/Space+Grotesk)
Fetched via the Google Fonts CSS API v2 (family=Space+Grotesk:wght@500;600;700),
latin subset only — the API served the same gstatic URL for all three
requested weights, confirming this is the single variable-font asset rather
than three separate static instances.
